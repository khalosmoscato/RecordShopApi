# RecordShop API

A RESTful API built with .NET 8/10 for managing a vinyl record shop inventory.

## Tech Stack
- **Language:** C#
- **Framework:** ASP.NET Core
- **Testing:** xUnit, TDD
- **Formatting:** CSharpier
- **Git Hooks:** Husky.Net

## Getting Started
1. Clone the repository.
2. Run `dotnet restore`.
3. Run `dotnet run --project RecordShop.Api`.
